# Lab01 — Hello Flow

Workflow manual em `.github/workflows/helloFlow.yml`. As variantes manual, agendada e por push estão em `referencias/`. Para demonstrar outra variante, copie-a para o workflow ativo e crie um novo commit. O agendamento precisa estar na branch padrão.

Este repositório final reúne os arquivos essenciais em um novo histórico. Os seis projetos e seus históricos originais permanecem preservados localmente. Execuções GitHub Actions ainda não foram realizadas.
